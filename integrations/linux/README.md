# Linux entry points

`redtooth install-integrations` adds **Send with Redtooth** to *Open With*, a Files (Nautilus) script, and a Redtooth launcher.
Requires BlueZ (`bluetoothctl`), PipeWire or PulseAudio (`pactl`), `libnotify` ≥ 0.7.9 for Accept/Decline in notifications,
and optionally `wpa_supplicant` with P2P for Wi-Fi Direct.
